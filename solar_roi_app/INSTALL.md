## 🚀 ขั้นตอนการติดตั้ง (Windows)

### ขั้นตอนที่ 1: ติดตั้ง Python

1. ดาวน์โหลด Python จาก https://www.python.org/downloads/
2. เลือก Python 3.9+ (แนะนำ Python 3.10 หรือใหม่กว่า)
3. ในขณะติดตั้ง **ต้องทำเครื่องหมาย** "Add Python to PATH"
4. คลิก "Install Now"

### ขั้นตอนที่ 2: ตรวจสอบ Python

เปิด PowerShell หรือ Command Prompt และพิมพ์:
```bash
python --version
```

ถ้าเห็น version number แสดงว่าติดตั้งสำเร็จ

### ขั้นตอนที่ 3: ดาวน์โหลด Project

1. ไปที่ `c:\Users\User\Downloads\STP Solar`
2. โปรแกรมอยู่ในโฟลเดอร์ `solar_roi_app`

### ขั้นตอนที่ 4: ติดตั้ง Dependencies

**วิธีที่ 1: ใช้ไฟล์ BAT (ง่ายที่สุด)**
1. ไปที่โฟลเดอร์ `solar_roi_app`
2. ดับเบิลคลิก `start.bat`
3. ปล่อยให้ติดตั้ง dependencies อัตโนมัติ

**วิธีที่ 2: ใช้ Command Line**

เปิด PowerShell ในโฟลเดอร์โปรแกรม:
```bash
# ไปที่โฟลเดอร์
cd "c:\Users\User\Downloads\STP Solar\solar_roi_app"

# สร้าง virtual environment
python -m venv .venv

# เปิดใช้ virtual environment
.\.venv\Scripts\Activate.ps1

# ติดตั้ง packages
pip install -r requirements.txt
```

## 📊 ความหมายของผลลัพธ์

### 💰 ต้นทุนเงินทุน
- ราคาทั้งหมดสำหรับติดตั้งระบบ
- ประมาณ 80,000-100,000 บาท/kW

### ⚡ การผลิตต่อปี
- พลังงานที่ระบบผลิตได้ต่อปี (kWh)
- ขึ้นอยู่กับตำแหน่งและขนาดระบบ

### 💵 รายได้ต่อปี
- เงินที่ประหยัดได้จากการใช้พลังงานโซลาร์
- = การผลิต × ราคาไฟฟ้า

### ⏱️ Payback Period
- กี่ปีระบบจะคืนทุน
- โดยทั่วไป 6-10 ปี

### 📈 ROI 25 ปี
- ผลตอบแทนของการลงทุน (%)
- เปอร์เซนต์กำไรในระยะ 25 ปี

### 💸 เงินออมรวม 25 ปี
- เงินที่ประหยัดได้ใน 25 ปี
- = เงินได้รับ - ต้นทุนและบำรุงรักษา

### 🌞 GHI (Global Horizontal Irradiance)
- ปริมาณรังสีอาทิตย์
- ต่อวัน: kWh/m²/วัน
- ต่อปี: kWh/m²/ปี

### 📈 กราฟกำไรสะสม
- แสดงการเพิ่มขึ้นของกำไรตามปี
- ใช้ดูเมื่อไหร่ระบบจะคืนทุน

## ❓ ถามหรือทำงานไม่ได้?

### ปัญหา: ไม่เห็นแผนที่

**แก้ไข:**
- ตรวจสอบ Internet connection
- ลองรีเฟรชหน้า (F5 หรือ Ctrl+R)
- ลองใช้เบราว์เซอร์อื่น

### ปัญหา: ปุ่ม "คำนวณ ROI" ไม่ทำงาน

**แก้ไข:**
- ตรวจสอบว่ากรอกข้อมูลครบหรือไม่
- ตรวจสอบเซิร์ฟเวอร์กำลังทำงาน (จะเห็นข้อความ "Running on http://127.0.0.1:5000")

### ปัญหา: เซิร์ฟเวอร์ไม่เริ่มต้น

**แก้ไข:**
- ตรวจสอบ Python ติดตั้งแล้ว: `python --version`
- ลบโฟลเดอร์ `.venv` และติดตั้งใหม่
- ลองเรียกใช้จากอื่น PowerShell window

### ปัญหา: ข้อความ "ModuleNotFoundError"

**แก้ไข:**
- ติดตั้ง dependencies อีกครั้ง:
  ```bash
  pip install -r requirements.txt
  ```
- ตรวจสอบว่า virtual environment ใช้งานได้
